# 本地编辑器

```powershell
npm ci
npm test
npm run build
npm run dev
```

构建产物位于 `dist/`，由 Windows 宿主通过本地 WebView2 虚拟域名载入。没有 CDN、外部字体或浏览器端 AI 请求。项目级 `.npmrc` 固定公开 npm registry 并跳过依赖生命周期脚本；浏览器编辑器不依赖 Fabric 的可选 Node Canvas 绑定。

桌面捕获默认进入选区附近的紧凑编辑层，冻结桌面只留在原生背景。原样画布按虚拟桌面物理选区映射定位，美化留白向外扩张。图片、文字、标注和导出均与完整工作台共用一个文档；「更多 → 完整工作台」是主动的高级入口。普通图片导入仍进入工作台。

原样与美化之间切换或调整留白时，已有标注会随原图内容平移。文字重排使用阅读卡片画布坐标，进出文字重排时不自动迁移标注。

浏览器模式可导入或拖入 PNG/JPEG/WebP，粘贴图片，保存/打开本地 JSON 项目，输出 PNG。桌面捕获、服务设置、OCR 和翻译需要原生宿主。用户必须显式点击 OCR/翻译才调用服务。图片、文字和项目文件不会自动上传。

JPEG/WebP 导入后在本地规范化为 PNG；原样 1×、没有裁剪/缩放/标注的 PNG 直接保留原始数据。美化与文字重排使用画布同源渲染，2× 为位图尺寸放大。标注支持可移动、缩放、旋转的文字、矩形、箭头、高亮与不透明实色遮盖；可调整选中对象的颜色和文字字号。

项目 schema v2 保留不可变原图引用，记录原图坐标裁剪框和等比输出尺寸，兼容打开 v1。裁剪/缩放会同步映射标注并可撤销。导出 PNG 的遮盖是实色，但可编辑项目与历史仍含原图，不能当作安全脱敏分享格式。OCR 处理图只含当前裁剪/缩放后的图片内容，不含美化背景或标注。

文档历史覆盖模式、样式、文字、标注、AI结果及裁剪/缩放，最多保留80步和8MiB编辑元数据；源图引用不按步复制。连续输入合并为短事务，对象拖动在完成时提交一次。新编辑清除重做分支，新图片/项目重置历史。Ctrl+Z/Ctrl+Y（或Ctrl+Shift+Z）仅在非文字输入/IME上下文控制文档历史，文字编辑保留原生撤销。

项目只恢复受限字段，不执行 Fabric JSON，不接受远程图片或 SVG。尺寸、字符数、对象数与导出像素总量均有限制。AI 请求带超时与关联 ID，切换图片/项目或修改文字后不会应用旧结果。

可将环境变量 `PLAYWRIGHT_MODULE` 指向已有的 Playwright 模块，再运行 `node scripts/headless-overlay.cjs`。脚本固定使用全新 `headless:true` Edge 会话、合成 PNG 和模拟桥接，不安装依赖，不连接现有浏览器，不调用真实原生操作或系统剪贴板。结果保存到忽略目录 `output/headless-overlay.json`。这验证了 DOM/CSS 坐标与协议生命周期，不能替代真实 WPF/WebView2 合成显示的人工验收。
