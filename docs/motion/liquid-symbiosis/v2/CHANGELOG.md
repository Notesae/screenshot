# v2 修订记录

## 与 1.0 的差异

- 从偏功能陈列的原型，回到原 G 的暖泥触感和多层运动；同时保留深暖灰对照。
- 调试侧栏默认收起，主区域用于实际交互；控件标签不再完全依赖悬停猜测。
- 实际加入邻居按压冲量、可见的短暂液桥、错峰挤出、卡片表面成长、一次扫光、松手脉冲、成功聚合与有限取消碎屑。
- 点击区域与外观分离；最大偏移按向量长度约束。蓝色选择由点击驱动，不由 hover 驱动。
- 从独立端点夹紧改为整体对象移动约束，防止拖到边缘时标注被压扁。
- 颜色有草稿和确认；保存预设不再只是提示；项目包含图片像素，能够往返；PNG 可实际导出且不包含界面。
- 任务均有身份保护；快速切换、连续捕获和退出中断有明确终态。
- 表单切页保留草稿，自绘下拉、颜色弹层、同源滑杆和可中断折叠替换部分粗糙的默认交互。

## 本轮开发中实际发现并修复

以下是 v2 验证中发现的问题，不冒称全部来自旧版本：

1. 错误通知位于底部，会挡住完成按钮，正常点击无法重试。改为按空间避让工具轨，正文不拦截点击；新任务清理旧通知。未用强制点击绕过测试。
2. 设置中的校验消息出现在模态后层。改为当前模态内的可见错误反馈。
3. 完成清空后再次开始框选，Esc 可能恢复空编辑状态。没有旧文档时回到已结束状态，不复活旧图。
4. 图像区域在浏览器缩放布局后，重新裁剪的坐标未同步原冻结图比例。裁剪改为按 source / stage 比例映射。
5. 裁剪后已有标注可能在图像外；若项目校验只允许当前图像边界，会拒绝自己保存的项目。保留有界的离画布坐标，预览和 PNG 同时裁切到实际图像范围。
6. 关闭弹出选择器后，触发器可能保留过期 aria-expanded。关闭统一复位并归还焦点。

7. 尺寸胶囊 Y 位移读取多了一层 `.x`，产生无效 transform。修正取值并验证拖动与回流。
8. 导入图片的上/下手柄只读取横向变化，无法缩放。改为按拖动方向选择比例，保持宽高比与固定端，输出像素不变。
