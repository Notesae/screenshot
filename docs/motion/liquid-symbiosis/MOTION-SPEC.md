# Liquid Symbiosis · 动效规范 1.0

本规范是**提议值与行为契约**，不是已实测的 Windows 性能承诺。权威参数为 `tokens.json`。默认质量为 full；系统减少动态具有更高优先级。

## 1. 四档表达强度

| 语义级别 | 候选系数 | 场景 | 保留 / 禁止 |
|---|---:|---|---|
| hero | 1.00 | 工具轨感知、截图交接、明确完成 | 群体牵引、局部形变、受限短液桥 |
| editing | 0.55 | 预设、属性、标注工具状态 | 更小受力；实际几何不缓动 |
| system | 0.20 | 设置、菜单、输入、确认 | 容器过渡；不让字段跟指针走 |
| reading | 0.00 | OCR 校对与阅读正文 | 正文静止，容器单独进出 |

系数不是把所有数值相乘。位移/形变受系数缩放；点击有效性、超时、任务进度及提示阅读时长不受它影响。Demo 的完整连续感知只实现于主工具轨，辅助组件使用简化过渡。

## 2. 分层模型

`HitTarget → VisualFace → ContentGlyph` 三层不可合并。

HitTarget 是固定 DOM 按钮/WPF 布局槽位，负责焦点与输入；VisualFace 只绘制曲面与形变；ContentGlyph 只做更小的位移，不继承非均匀缩放。液桥与底座装饰都设置为不命中。

每条工具轨有一个群体调度器、一份几何缓存、一套休眠规则。不要每个按钮创建独立无限 RAF。按钮有自己的当前位移、速度、受力和视觉权重；群体调度器决定它们之间的约束。

## 3. 临近感知场

### 3.1 输入

只有 fine pointer + hover 才启用预感知。输入为 CSS 像素指针 `p`、稳定布局中心 `c_i`、半径 R、按钮组和当前业务状态。触摸/笔直接进入按压反馈；键盘焦点使用明确焦点材质，不模拟虚假的鼠标靠近。

默认 R=108，调校范围 60–150。感知函数采用紧支撑核：

```
d_i = length(p - c_i)
w_i = max(0, 1 - (d_i/R)^2)^2
```

R 外没有反应。相邻影响只在同组内计算：第一邻居 0.22，第二邻居 0.07，之后为0。总权重裁到 [0,1]，不因为按钮更多而把整条轨道放大。

默认局部水平目标上限2.4px，垂直3.2px；合成向量总上限4px，作为硬约束。完成与收起只有低幅自主回应，不接受邻近液桥。按钮与组分隔符的碰撞空间优先于形变幅度。

### 3.2 平滑与惯性

采用二阶系统 `x'' = k(target-x) - c*x'`，mass=1。使用实际帧时间 dt，不以“每帧固定移动几像素”更新。[参考：requestAnimationFrame]

原型采用半隐式 Euler，小步长 ≤1/120s，单帧累计推进上限50ms，防止标签页恢复后跳跃。位置误差<0.01px且速度<0.06px/s时吸附目标；连续8帧均停稳且没有短期桥接/指示转移任务后停止 RAF。

| 语义弹簧 | k | c | 用途 |
|---|---:|---:|---|
| attention | 520 | 34 | 目标按钮临近反馈 |
| neighbor | 360 | 30 | 邻近传导与回流 |
| body | 260 | 30 | 底座承托形变 |
| press | 720 | 34 | 明确按压与恢复 |
| indicator | 520 | 38 | 生产激活态迁移候选 |
| panel | 400 | 38 | 生产浮卡形变候选 |

原型中的 indicator/panel 使用有限时长过渡近似，不声称与生产弹簧求解完全一致。生产适配必须选择单一时间模型并重新核验所有平台；不要把 CSS 曲线与弹簧参数同时当作同一动效的权威。

### 3.3 按下冻结

pointerdown 后冻结当前局部吸引目标；按压表面横向最多1.045、纵向0.90；受力不改变 HitTarget。pointerup 由标准 click 执行业务。pointercancel/lostpointercapture/失焦恢复外观并撤销未提交手势。[参考：Pointer Events]

按住时长不解释为“真实压力”，不使用鼠标速度推断用户心理。仅用已经可观察的位移/速度塑造很小的惯性差异，不改变行为结果。

## 4. 群体承托

底座位移≤0.7px，局部隆起≤2px。它响应的是局部权重的质心，不是简单把整条轨道跟着鼠标跑。

邻近按钮传导应与当前输入方向一致；离开时从当前位置与速度回流。不得重复叠加新 spring，导致相同属性同时被多个写入者修改。

在连续拖框、调整选区、拖动工具轨、原生模态开启或业务锁定期间停止临近感知；释放后根据新指针位置重新进入。拖动轨道使用直接位移，不叠加磁吸来拖慢手势。

## 5. 短暂融合 / 液桥

### 5.1 允许触发

A→B 同组邻近跨越；明确同组工具切换；按钮→近距离属性卡展开。稳定悬停不持续生成；普通鼠标位移不产生全轨道融合。

### 5.2 硬约束

- 同时最多1条按钮液桥；持续窗口160ms。
- 按钮可见间隙≤14px；颈部目标4px；不透明度≤0.40。
- 不跨组；不跨滚动裁切；不连接禁用、危险、完成、收起按钮。
- 浮卡桥仅在实际边缘跨度≤48px时成立。远距离、翻转摆放和手动移位使用无桥方向过渡。
- bridge 永远不参与命中、焦点、导出或布局计算。
- 允许在快速反向时改变牵引方向；不得出现累积长丝和第三条桥。

使用局部 SVG 路径表达收颈。原型不采用全屏 GaussianBlur/goo filter。生产可以选择更复杂的局部融合，但必须保持边界和性能预算，不能以全屏滤镜获得同类效果。

### 5.3 色彩语义

邻近连接为中性材质色；明确工具选择转移可以使用蓝色。选中层与 hover 层互不覆盖：当前工具被选中时，悬停其他按钮不撤掉当前蓝色，也不在两个无关动作上同时伪造选择。

## 6. 典型时间线

所有时间相对于真实触发事件，而不是页面加载时刻。

### 6.1 框选与编辑交接

| 时间 | 事件 | 表现 | 输入 |
|---|---|---|---|
| 按下至松手 | 实际框选/调整 | 精确边界与读数直接跟随 | 始终处理手势 |
| 松手 | 提交当前捕获/几何 | 保留当前冻结画面，等待合法呈现 | 取消可用 |
| 正确捕获被宿主显示 | 当前画布 ready | 工具轨短展开，按钮表面落定 | 业务就绪即允许，不等动画 |
| 0–260ms 装饰尾部 | 来源方向展开 | 同一底座承托按钮，不整条漂移 | 不延后点击 |
| 停稳后 | 编辑待机 | 无呼吸与扫光 | 仅响应新的输入 |

必须分别记录“松手→宿主可呈现”“可呈现→可点”“可点→装饰停稳”。前一阶段可能由捕获或 GPU 决定，不能只测 CSS 动画就宣称端到端达标。

### 6.2 属性卡展开和切换

点击马上更新 panel 状态；固定最终面板布局后，从触发器方向进行260ms小幅形变；内容在容器稳定可读的阶段以120ms淡入。文字不按比例挤压。

同按钮再次点击收回，180ms；关闭后归还焦点。A 卡切 B 卡从当前可见形态重定向，而不是把 A 播完再播放 B。面板拖动后以当前位置收起，不能瞬移回旧按钮。空间不足时先做最终避让，动效跟随真实方向。

原型使用 WAAPI scale/translate 近似容器来源形变；生产应使用独立表面与反向缩放的内容，或独立内容层。关闭过程立即 inert，但不能过早卸载表面。

### 6.3 异步任务

收到点击即进入请求状态；任务状态源驱动提示，不用固定时间表假装识别已完成。短任务避免多次闪烁；长任务维持轻量等待并允许取消。

成功：结果原子提交→短淡入→可校对。失败：原内容保留→持久错误→重试。空结果：保留旧结果→说明。部分失败：成功块保留→失败定位→按失败块重试。取消：使请求失效→清等待→回到已有编辑。过期：拒绝回填→不给新文档播成功。

### 6.4 完成输出

```
editing
  → preparingOutput(snapshot identity)
  → copying
  → copied + identity checked
  → host exit authorized
  → short success exit
  → host hidden + matching document cleared
```

点击后的受力65ms；准备与复制时长由真实任务决定，不能压成固定300ms；只有成功确认之后，退出装饰目标300ms，硬上限候选380ms。

任一步失败回到可编辑状态。复制完成但关闭身份失效时保留编辑并说明真实状态。新截图开始使旧退出令牌失效；所有延迟淡出和 toast 都绑定自己的任务/会话，不得关闭新窗口。

### 6.5 取消与层级返回

局部取消只作用于当前层。收起整个截图时低强度180–300ms回流，不用碎屑、塌落或“已复制”庆祝。正在输入或选择文本时尊重文本与输入法，不把第一个 Esc 当结束会话。

## 7. 状态优先级与中断

从高到低：安全/宿主锁定 → 活动手势或模态所有者 → 任务取消 → 文档状态 → 明确工具选择 → 按压 → hover/临近 → 装饰。

每个表现属性只能有一个最终写入者。新意图更新目标，而不是排队；必须携带 owner、runId、documentId、revision、captureId（按场景需要）。业务结果不由 animationend 回调判定；动画结束只负责清理本轮表面。

原生和网页不能各自播放一份相同选区边界，造成双影。离开、任务取消、页面隐藏、组件卸载、pointercancel 都应清理对应监听、捕获、帧回调、延时与临时 SVG。

## 8. 减少动态与低开销

优先级：系统减少动态 OR 应用减少动态 → reduced；否则低开销→economy；否则 full。用户不能在应用里关闭系统保护。[参考：prefers-reduced-motion]

| 维度 | Full | Economy | Reduced |
|---|---|---|---|
| 固定输入/命中区域 | 保留 | 保留 | 保留 |
| 临近轻位移 | 有 | 降低成本地变换 | 0 |
| 群体底座/形变 | 有限 | 可保留简单 transform | 0 |
| 按钮液桥/浮卡桥 | 有条件 | 关闭 | 关闭 |
| 跟随光 | 低强度 | 关闭 | 关闭 |
| 主体切换 | 短形变 | 简化位移/淡入 | ≤120ms 透明度 |
| 等待反馈 | 局部转动或阶段文字 | 局部简化 | 静态标记+阶段文字 |
| 空闲循环 | 无 | 无 | 无 |

运行中切换模式必须立即取消已开始的运动、落到正确静态状态，不能只影响下一个动画。Reduced 不保留暗角弹簧或“看似关闭但仍在跟随”的隐藏运动。开关只影响表现，不改变任务/文档/历史。

## 9. 性能候选门槛

| 指标 | 候选值 | 当前验证边界 |
|---|---:|---|
| 输入→首次视觉确认 | 目标≤50ms | 未完成端到端设备测量 |
| 画布就绪→首个可点 | 目标≤120ms | 原型不等待装饰，Windows待测 |
| 画布就绪→全部可点 | ≤220ms | 待生产测量 |
| 装饰停稳 | ≤500ms | 原型有休眠断言，无刷新率性能保证 |
| 已确认成功→隐藏 | ≤380ms | 原型300ms时长，非实机延迟实测 |
| 全会话取消→隐藏 | ≤300ms | 原型180ms，非WPF保证 |
| reduced 单次过渡 | ≤120ms | 原型设置100ms |

缓存按钮布局；在 ResizeObserver、滚动、DPI/工作区及按钮集合变化时失效。pointermove 不读写交错触发布局。只在活跃阶段调度帧。图标不做滤镜，截图像素不做运动模糊，不在大图导出时继续跑装饰。GC、GPU与WebView2合成成本必须在授权的Windows验收中测量。
