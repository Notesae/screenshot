# v2 动效生产接入

日期：2026-10-22。基于 design/liquid-symbiosis 的 e478516，在 codex/liquid-motion-v2 实现。参考 docs/motion/liquid-symbiosis/v2 的 DESIGN、MOTION-SPEC、tokens 和 demo/engine.js；原型本身保留。

## 已接入

- React 与 WPF 只消费 v2/tokens.json 的 motion 节。材质、字体、圆角和控件尺寸继续使用 design/soft-clay.tokens.json，没有引入原型主题切换或第三方动效依赖。
- 固定按钮语义槽位、独立变形表面、仅平移的图文。按钮主动迎向、同组第一/第二邻居传导、按压冲量及蓝色选中面迁移；跨同组近邻时只出现一条短液桥。
- 工具轨底座展开，完成端最先挤出，其他表面按 14ms 错峰；布局槽位在宿主揭示后立即可操作，视觉进度不吞点击。单次扫光和选区脉冲不会在等待验帧期间提前播放。
- 浮卡材质从来源槽位生长，正文独立淡入；近距离才绘制卡片液桥。快速切换从当前矩形续接，旧关闭回调不能移除新卡。关闭约 170ms，折叠区约 190ms，可从当前高度反向。
- 尺寸读数即时更新，胶囊外壳只保留 5/4 CSS px 以内短惯性。所有截图、标注和导出坐标仍由现有内核处理。
- 完成：生成 PNG → 真实复制成功 → 文档/修订/代次/捕获身份复核 → 约 360ms 展示副本收束 → 再次复核 → 原生 presentation.complete 确认并隐藏。展示副本来自现有本地画布，不是屏幕捕获，不参与 PNG 输出。
- 等待时可取消完成/按 Esc 作废收起意图；已经提交给系统的复制不能回滚。取消退场或新截图会取消旧退出链，失败恢复原表面。普通收起下沉并保留文档，不冒充成功。
- 系统减少动态会将进行中时间线归到正确终态；位移、液桥、粒屑、扫光关闭。低核心设备关闭装饰追光和液桥；连续五帧静止后网页帧循环休眠。
- WPF 按钮模板分离材质与图文，使用同源有界弹簧；托盘菜单短位移淡入，保留原生键盘导航。所有原生控件停稳后解除 Rendering 订阅。
