# v2 动效生产接入

日期：2026-10-22。基于 design/liquid-symbiosis 的 e478516，在 codex/liquid-motion-v2 实现。参考 docs/motion/liquid-symbiosis/v2 的 DESIGN、MOTION-SPEC、tokens 和 demo/engine.js；原型本身保留。

## 已接入

- React 与 WPF 只消费 v2/tokens.json 的 motion 节。材质、字体、圆角和控件尺寸继续使用 design/soft-clay.tokens.json，没有引入原型主题切换或第三方动效依赖。
- 固定按钮语义槽位、独立变形表面、仅平移的图文。按钮主动迎向、同组第一/第二邻居传导、按压冲量及蓝色选中面迁移；跨同组近邻时只出现一条短液桥。补齐同源渐变桥材质、双轴追光、表面与底座曲率；鼠标和键盘按压共用反馈。
- 工具轨底座展开，完成端最先挤出，其他表面按 14ms 错峰；布局槽位在宿主揭示后立即可操作，视觉进度不吞点击。单次扫光和选区脉冲不会在等待验帧期间提前播放。
- 浮卡材质从来源槽位生长，正文独立淡入；近距离才绘制卡片液桥。快速切换从当前矩形续接，旧关闭回调不能移除新卡。关闭约 170ms，折叠区约 190ms，可从当前高度反向。下拉、取色、工具提示、通知及阅读窗口共用保留表面的进退场；关闭立即停用命中和辅助树，重开取消旧关闭。材质和正文透明度分别续接，避免正文尚未出现时关闭导致材质闪断。
- 尺寸读数即时更新，胶囊外壳只保留 5/4 CSS px 以内短惯性。所有截图、标注和导出坐标仍由现有内核处理。原生首次框选也接入同源弹簧：胶囊惯性和控制点有限体积反馈仅更新局部脏区，停稳关闭计时器；松手交接和系统减少动态立即归位。
- 完成：生成 PNG → 真实复制成功 → 文档/修订/代次/捕获身份复核 → 约 360ms 展示副本收束 → 再次复核 → 原生 presentation.complete 确认并隐藏。展示副本来自现有本地画布，不是屏幕捕获，不参与 PNG 输出。
- 等待时可取消完成/按 Esc 作废收起意图；已经提交给系统的复制不能回滚。取消退场或新截图会取消旧退出链，失败恢复原表面。普通收起下沉并保留文档，不冒充成功。
- 系统减少动态会将进行中时间线归到正确终态；位移、液桥、粒屑、扫光关闭。低核心设备关闭装饰追光和液桥；连续五帧静止后网页帧循环休眠。
- WPF 按钮模板分离材质与图文，使用同源有界弹簧；托盘菜单短位移淡入，保留原生键盘导航。所有原生控件停稳后解除 Rendering 订阅。

## 实现入口

- editor/src/motion.ts：有界半隐式欧拉弹簧、命名中断和休眠时钟。
- editor/src/LiquidMotion.tsx：固定命中按钮、主轨感知、浮卡与退场控制器。
- editor/src/SurfaceMotion.tsx：五类小弹层的材质/正文分离、当前矩形续接及退出保留；手动移动/缩放即时接管。
- editor/src/MotionDetails.tsx：原生 details 语义下可中断折叠。
- src/Screenshot.App/SoftClayMotion.cs：WPF 材质/图文反馈、托盘入场及网页同源求解器。
- src/Screenshot.App/CaptureMotion.cs 与 CaptureService.cs：原生首次框选的纯装饰状态和有限脏区绘制，不修改选区模型。
- 原有 App/CompactOverlay 与 WPF 主题仅增加表现衔接；Fabric、项目格式、AI 和原生捕获权限不变。
