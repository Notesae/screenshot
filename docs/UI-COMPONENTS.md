# 界面与组件约定

本项目继续使用 Soft Clay 暖灰表面、深色输入区和蓝色主操作。以下约定覆盖网页编辑器、设置、条款、历史记录、托盘和应用内提示，优先于各文件中较早的视觉记录。

| 职责 | 唯一来源 |
|---|---|
| 颜色、圆角、字号、间距、尺寸和状态 | `design/soft-clay.tokens.json` |
| 网页 token 注入 | `editor/src/softClayTokens.ts` |
| 网页控件、焦点、悬停、按下、禁用、错误 | `editor/src/controls.css` |
| 网页浮层与画布布局 | `editor/src/soft-clay.css`；`styles.css` 仅保留重置及结构 |
| 下拉、颜色面板、悬停提示 | `Select.tsx`、`ColorField.tsx`、`TooltipLayer.tsx` |
| WPF token 注入与 WinForms 框选绘制 | `SoftClayTheme.cs` |
| WPF 控件、菜单、字段、提示和浮层表面 | `SoftClayControls.xaml` |
| WPF 无描边曲面、凸面和凹面的内高光/阴影绘制 | `SoftClaySurface.cs` |
| 网页 / WPF 覆盖式滚动条与空闲隐藏 | `editor/src/OverlayScrollbars.tsx` / `OverlayScrollbars.cs` |
| WPF 应用内错误与确认 | `SoftClayDialog.cs` |

正文为 13 DIP，标签/辅助文字 12 DIP，浮层标题 15 DIP；常规控件 40 DIP，工具与菜单行 36 DIP，核心控件与浮层圆角均为 12 DIP。WPF 与 CSS 使用相同的逻辑像素尺度；GDI 字号转换为点数后随 DPI 绘制。

最终材质以原截图操作导轨为准，保留多段暖灰曲面、凸起按钮、柔和内高光、底部阴影和按压回弹。导轨采用原四段曲面，大浮卡与菜单采用原属性卡的双段暖灰渐变；内高光和暗部限制在边缘的柔和区域，不以轮廓线替代材质。中性按钮、输入区、下拉触发器、菜单项各有固定角色；主操作及工具选择使用原有蓝色凸面，导航使用中性凸面，列表选择使用中性底色，危险操作使用错误色。控件与浮层不绘制装饰外沿或焦点环，也不保留输入底部的细亮线或内容分组分隔线，以留白表达分组。悬停、展开和键盘焦点使用共享填充或亮度变化，不依赖浏览器 outline 或 WPF 系统焦点装饰，状态变化不改变布局占位。截图选区、标注和图标线条按原有功能保留。禁用态使用共享 0.42 透明度与真实 disabled/IsEnabled 语义。

WPF 通过 `SoftClaySurface` 绘制浮卡、按钮、字段和下拉的柔和内高光/暗部，公共样式指定材质角色，不在某个设置页另画一个边框。单行 TextBox、PasswordBox 和下拉保持 40 DIP，内容宿主只传递一次 Padding，不再重复叠加 Margin；条款正文与更新说明继续支持多行滚动，更新说明使用无输入井的只读文字样式。

折叠标题最小高度 40 DIP，左右 12 DIP、上下 10 DIP 内边距，文字与箭头各有固定留白，WPF 展开内容内缩 12 DIP。设置页的服务管理入口随列表和更多设置放置，表单固定区只承载当前服务反馈、测试/取消及保存；保存与测试共用一处消息，截图页反馈留在截图页，使用条款位于窗口标题栏右侧。

横竖滚动条均覆盖在内容上，不预留宽度或高度，不使用稳定 gutter。共享 `scroll` token 规定 10 DIP 命中区域、4 DIP 滑块、24 DIP 最短滑块、1200ms 空闲隐藏和 160ms 淡出；拖动和滑块悬停期间保持显示，隐藏后让出命中区域。WPF 保留标准 ScrollViewer/ScrollBar 部件和命令，网页保留原滚动容器、滚轮、键盘和触摸行为，只在根层绘制滑块；滑块须跟随嵌套裁切，弹层不能将自己滑块上的操作当成外部点击。网页禁用原生滚动条的标记使用独立 data 属性，不与 React 管理的 className 竞争；尊重减少动态效果设置。

设置三页的页面滚动使用 `ClayPageScrollViewer`：滚动区域向右延伸 16 DIP，内容补回 16 DIP 内距，让滑块靠近浮卡右边、表单保持原宽度；服务页的标题和操作区仍固定。普通文本井、服务列表和弹出菜单继续使用各自容器边缘，不套用页面的外延布局。ScrollViewer 背景保持透明但可命中，使空白区域和浮卡侧边也能接收滚轮/悬停。

不在某个面板内再声明一套按钮、输入框、下拉或滚动条模板。确需不同密度时仅调整容器布局和明确的紧凑尺寸，不改变颜色及状态定义。内容色值（截图背景、标注和预设）属于文档数据，与界面主题分开维护。

下拉和取色弹层挂在编辑器根层，避免被浮卡滚动区截断。颜色草稿经确认后才写入文档；Escape/外部关闭不提交草稿。取色提供 RGB 滑杆及十六进制输入，键盘用户可使用标准按钮、方向键和 Tab。悬停提示通过 data-tooltip 提供，不混用浏览器原生 title 弹层。

设置、条款和应用内确认框使用同一浮层表面及关闭按钮。下拉模板必须传递 SelectionBoxItemTemplate 和 ItemTemplateSelector；文档列表显式使用标题模板，不能把对象 ToString 显示为标签。系统文件/文件夹选择保留既有接口；本轮没有重新实现系统文件管理器，也没有把密钥、原生权限或任何新桥接能力交给网页。

当前阶段只编译，不运行测试、样式检测器、浏览器或原生窗口。以上为代码与设计约定，不能视为实机视觉、键盘、IME、DPI 或无障碍验收结果；限制见 `VALIDATION.md`。
