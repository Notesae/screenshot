# Screenshot v@VERSION@ 预发布版

固定提交：`@COMMIT@`；[对应 Windows 验证 CI](@CI_URL@)。附件取自该提交成功的主分支 CI，不在发布阶段重新构建。

- [安装版 MSI](https://github.com/Notesae/screenshot/releases/download/v@VERSION@/Screenshot-@VERSION@-setup-x64.msi)：中文界面，安装给当前 Windows 用户，提供桌面、开始菜单和系统卸载入口。
- [便携版 ZIP](https://github.com/Notesae/screenshot/releases/download/v@VERSION@/Screenshot-@VERSION@-win-x64.zip)：完整解压到新目录，再双击根目录的 `Screenshot.exe`。

本版合入 [PR #5](https://github.com/Notesae/screenshot/pull/5)，统一截图、编辑、设置、条款与菜单的 Soft Clay 质感，并改进原位翻译和长文阅读。

- 界面沿用原截图操作导轨的暖灰渐变、柔和阴影与按压反馈，去除装饰描边和系统蓝色焦点框，使用底色表达焦点及选择。统一字段、下拉和折叠标题的高度与内边距，整理服务设置操作区。滚动条覆盖在内容上，不占宽度，空闲时自动隐藏。
- 点击「完成」复制 PNG，成功后收起并结束本次编辑；复制失败或回复过期时保留当前编辑。关闭编辑、覆盖、退出和更新前的自动保存，需要保留可编辑内容时请手动保存项目。既有恢复记录仍可主动查看或清理。
- 调整框选到编辑器的绘制交接，核对当前截图、视口、DPI 与实际合成图像，防止迟到响应或旧画面替换新截图；保留失败、取消与超时保护。
- 图片翻译优先使用本地 OCR 的文字框，仅发送识别文字给翻译服务；需要图片输入的视觉路线仍由用户明确触发。译文层保留原图、位置和排版，绘制限制在原文字框内，不扩大到相邻内容。超出空间时保留省略预览或原文，完整译文可在阅读窗口查看，并随手动保存的项目保留。
- 「阅读译文」默认以紧凑的连续内容呈现，可切换原文对照、调整字号，拖动标题栏移动窗口，并从角落调整大小；同一截图中关闭再打开保留手动位置。文字面板默认收起识别设置，移除冗余说明、复制换行设置和文字卡片生成区。

应用更新使用官方公开源，免登录。默认只检查稳定版，本次为预发布版，便携版用户需主动选择「稳定版及预发布」。MSI 安装版请保存并退出旧版后，通过新版 MSI 升级；便携 ZIP 应解压到全新目录，不覆盖正在使用的目录。用户设置和旧恢复数据继续使用原 Windows 用户目录。首次运行仍需确认条款，机器需具备 WebView2 Runtime。

验证沿用完整 Windows CI：前端测试/构建、.NET、固定合成输入的本地 OCR、存储及大图保护、无头界面/生命周期/翻译阅读回归、原生 OCR 性能门禁，以及便携包和 MSI 构建/离线提取校验。合成翻译回归检查原文字框外改变像素为 0，并覆盖阅读窗口拖动、缩放、对照、项目往返与 PNG 导出。原生 OCR 比较保留 1.15 门槛，失败即停止打包。详细证据与历史记录见 [验证记录](https://github.com/Notesae/screenshot/blob/@COMMIT@/docs/VALIDATION.md)。

这是预发布版，尚未完成真实 Windows 桌面验收和真实服务翻译质量验证。遵守桌面交互暂停要求，没有启动产品或运行 MSI；托盘、热键、WPF/WebView2 合成、多屏 DPI、IME、原生剪贴板、更新交接和安装/升级/卸载仍需实机验证。MSI 离线校验不等于安装验收。保留 Vite 主包体积提示及既有依赖审计限制，不宣称完成依赖安全审计、法律审查或发布者数字签名。

ZIP 大小 @ZIP_BYTES@ 字节，SHA-256：`@ZIP_SHA256@`。MSI 大小 @MSI_BYTES@ 字节，SHA-256：`@MSI_SHA256@`。条款目录摘要：`@TERMS_DIGEST@`。另附独立校验文件、SHA256SUMS.txt 和 release-manifest.json；发布流程回下载全部七个附件核对字节和摘要。
