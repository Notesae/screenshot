## 实际执行

本次使用 Linux 容器中的 Chromium 无头浏览器、Playwright Python 和合成图像。浏览器以 `page.set_content()` 加载打包 HTML，没有控制用户桌面。环境策略阻止 `file://` 导航，因此没有把此环境下双击本地文件写成已验收；独立 HTML 不需要外部资源。

共 **57 项原型检查通过**。这不是 57 项生产 Windows 功能验收，也不代表所有规范项都已实现。各组结果 JSON 随下载包提供，不提交仓库生成目录。

一次将任务组与系统组串联执行时超过容器单次命令时间限制，后半段驱动管道报 EPIPE；任务组已完成，系统组随后独立重跑通过。没有将被中断的执行写成通过。

## 视觉检查

已查看实际生成的主场景、美化及窄窗口截图，修正属性浮卡遮住工具轨的问题。演示在默认 1600×1000 视口，以及 1024×900、720×900、390×844 下检查页面横向溢出、完成按钮可达性和浮卡与工具轨是否重叠。手机宽度仅用于压力测试，不等于产品新增移动平台支持。

下载包 `previews/` 包含主流程、临近响应、美化、阅读、完成、设置、组件及窄窗口静态预览。静态截图不能证明完整运动质量；动态效果请操作 `standalone.html`。

测试中检查到按钮外观变形时语义命中盒坐标不变；鼠标离开并停稳后，连续观察窗口中的 RAF 帧计数不再增加。这里只验证休眠机制，不据此宣称节电比例或 Windows 帧率。

## 复现

```bash
python build.py
node --check demo/app.js
python -m pip install playwright jsonschema
# 当前脚本使用 /usr/bin/chromium；其他环境需改为本机路径，
# 或使用 Playwright 安装的 Chromium，删除 executable_path 参数。
python tests/qa.py --group core
python tests/qa.py --group tasks
python tests/qa.py --group system
```

测试在隔离浏览器中主动执行合成操作。需要本机已有 Python、Node、Chromium/Playwright；不包含静默安装步骤。正式应用测试工程、CI 和本机安装不受影响。

## 仍属于原型近似的部分

- 选区几何使用浏览器视口坐标，不是 Windows 虚拟桌面物理像素；原生窗口吸附、多屏与放大镜仅有规范。
- 绘图为轻量 SVG 行为原型，不是 Fabric 文档内核；未复现生产绘图、排版、重采样与导出全部能力。
- 临近感知、邻居传导与底座运动使用弹簧；卡片形变与激活指示使用有界插值近似。邻居点击冲量、真实流体求解和所有自动重排轨迹尚未实现。
- OCR、文字翻译、图片翻译、剪贴板完成、服务测试、更新和历史使用内置假数据。图片翻译仅展示两块固定原位文本，完整阅读使用四段合成文字，不是识别质量证据。
- 部分失败的重试用于体验恢复过程，不等同于实现生产按失败块精确续传。
- 文件导入只读取用户主动选择的本机图片；演示 JSON 有格式/字段白名单，但不是生产项目兼容。JSON 不保存导入图片像素。
- 原生设置、托盘、条款和更新窗均为 HTML 替身。原生控件模板、IME 和系统焦点未验证。演示中的下拉、颜色选择和滚动条部分沿用浏览器控件。
- 全应用低强度反馈、无障碍语义已给出规范及部分原型，但不是完整读屏或键盘可访问性认证。
