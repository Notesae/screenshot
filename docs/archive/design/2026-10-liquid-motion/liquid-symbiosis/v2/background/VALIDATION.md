# 背景候选方案验证

本页记录 Demo 阶段的验证。后续用户已授权正式接入；原生与 React 的实际检查范围见 `docs/LIQUID-MOTION-V2.md` 的“背景轻移正式接入”一节。

2026-10-22。仅独立无头浏览器及合成桌面；桌面交互暂停继续有效。

## 执行方法

使用项目外已有的 Python、Node、Playwright 和 Edge 155.0.4283.62；未安装依赖、下载浏览器或模型。受限沙箱不能启动无头 Edge，随后在获准的隔离无头环境执行同一脚本。脚本只向测试页面分发 DOM 事件，不发送真实鼠标、键盘或剪贴板操作。

`build.py` 生成独立单文件，`node --check background.js` 检查脚本语法；Impeccable 对本次新增 CSS/JS 的机械检查未报告问题。自动回归由 `test.cjs` 执行，最终结果写入忽略目录中的 `validation.json`。

最终 19 组回归全部通过，页面异常为 0，页面外部网络请求为 0。暖泥、深暖灰及窄窗口渲染图已人工检查；修正了启动中按住时的短跳变，并使用 v2 同款开关后完成一次复验。

## 检查范围

- 同向幅度、逐帧边界、快速反向时的位移与速度续接。
- 按住冻结、启动中按住、丢失捕获后恢复、离开回正和静态对照。
- 原始选区像素、PNG 导出、文档修订、选区和工具轨矩形一致。
- 图像四边及角落透明度、边缘扩展和可视区域覆盖。
- 框选归正、模态/阅读回正、模拟完成/新截图交接。
- 幅度调节、参数导出、系统和手动减少动态、低开销、粗指针。
- 页面隐藏/失焦停止调度，迟到指针不恢复隐藏动画，静止帧计数保持不变。
- 1440px 暖泥/深暖灰外观；1280、1024、720、390px 横向溢出和背景覆盖。
- 页面脚本异常与页面外部网络请求。

界面渲染预览保存在 `output/design/liquid-v2-background/preview-*.png`；它们是合成网页渲染图，不是真实桌面截图。生成页面、测试结果和参数导出均不加入 Git。
