# v2 接入边界与审阅入口

本轮交付可运行的独立原型，不直接替换 Screenshot 正式应用。保留原 G、v1 和当前生产代码，避免为了展示效果重写业务内核。

## 可迁移部分

`demo/engine.js`：统一可打断弹簧调度、按钮感知、同组邻近传导、按压冲量、稳定命中、液桥、激活迁移、入退场、停稳休眠。迁移时以现有 DOM 实测矩形作为目标，不能搬硬编码坐标。

`tokens.json`：候选值独立于生产 Token；暖泥用于原稿对照，dark 用于生产材质评估。全局控件尺寸与圆角不得未经确认一起覆盖。

## 不可直接搬运部分

`app.js` 的 SVG 标注、画布裁剪、内存文档与项目格式是浏览器原型，不是 Fabric 内核。真实应用应保留原有文档 ID、修订、撤销、导出与坐标映射，只接入表现层。

OCR、翻译、服务、剪贴板、更新、托盘和合成桌面不是生产能力。原生宿主继续独占密钥、OS 能力及权限。这里的模拟任务不能作为线上失败处理的替代。

## 完成协议

交互确认 → 生成图片 → 真实复制成功 → 校验当前文档/修订/捕获身份 → 通知表现层收束 → 动画结束或减少动态直接完成 → 原生隐藏。新截图、关闭或身份变化必须能使上一条完成链失效。任何失败都保留现场；不能先给“已复制”再等结果。

## WPF 与网页

共享语义参数，不共享 CSS 实现。原生截图边界严格使用物理像素，视觉层只消费 DIP/CSS 映射。原生到网页的 ready/painted/合成帧门控保留；浮层动画不可在被遮挡时提前播放。真实 Windows 验证仍需单独授权。

## 审阅顺序

先对比原 G 和 v2 的轨道生成、相邻桥接、卡片展开、确认收束；再检查快捷操作、输入、错误和窄窗口。视觉审阅通过前，不把本候选当作生产实施完成。
