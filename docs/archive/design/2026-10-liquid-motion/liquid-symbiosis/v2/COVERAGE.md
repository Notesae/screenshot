# v2 覆盖与真实性

P = 页面内可实际操作；M = 本地合成模拟；S = 生产规范/边界，不是本原型已实现。

| 范围 | v2 交付 | 级别 |
|---|---|---|
| 框选 | 拖动、八方向调整、移动、键盘调整、取消并恢复之前内容 | P；浏览器虚拟舞台 |
| 感知与群体 | 临近迎向、邻居传导、按压冲量、底座响应、液桥、选择迁移 | P |
| 主流程动效 | 轨道挤出、脉冲、扫光、卡片成长、完成聚合、取消下沉 | P；完成业务为 M |
| 标注 | 矩形、箭头、文字、高亮、实色遮盖；选择、移动、调整、属性、删除、撤销重做 | P |
| 美化 | 预设、留白、圆角、阴影、背景、边框、自定义预设保存/应用/删除 | P；预设仅本会话 |
| 颜色 | 草稿、预置色、十六进制校验、明确提交、取消 | P |
| 文件 | 用户主动选择图片、文件拖入、输入大小与像素上限 | P |
| 项目 | 图片像素及文档保存/打开、类型/字段校验、坏文件不替换旧内容 | P；独立 v2 格式 |
| PNG | 1×/2×、逐形状重绘、实色遮盖、排除 UI、像素上限 | P；非生产 Fabric 导出 |
| OCR | 识别等待、取消、源块、校对、空结果和部分失败 | M / P |
| 文字翻译 | 原译分离、校对、过期提示、失败保留现场 | M / P |
| 图片翻译 | 独立译文图层、单步撤销、完整阅读入口 | M；固定示例块 |
| 阅读 | 拖动、尺寸、重置、16–28px、原译对照、窄屏隔离后层 | P；正文是示例 |
| 完成 | 等待、取消、失败、过期、确认后收束、清空 | M；不写系统剪贴板 |
| 收起 | 保留当前文档，可显式恢复，与完成区别 | P |
| 托盘 | 应用内菜单和功能入口 | M；不创建 Windows 托盘 |
| 设置 | 字段草稿保留、服务新增保存删除、连接测试 | P / M；不收集密钥 |
| 更新 | 检查、下载、取消、失败、安装/回滚确认 | M；不操作安装目录 |
| 条款 | 勾选门控、拒绝和关闭、焦点隔离 | M；不是法律文本 |
| 基础组件 | 按钮、输入、滑杆、开关、自绘选择器、颜色、折叠、消息、模态 | P |
| 故障与输入 | 连续点击、反向移动、pointercancel、失焦、迟到结果、缩窄视口 | P；实际检查见 VALIDATION |
| 降级 | 系统 reduced 优先、运行中切换、低开销、静止休眠 | P |
| 原生接入 | WPF/WebView2 真实合成帧、混合 DPI、系统热键与剪贴板、真实服务 | S；未执行 |

本版本没有删除原 G Demo，也不把新原型视为现有应用功能重写。生产能力完整地图继续参考上级设计包，但不能将上级“规范覆盖”算作 v2 已实现。
