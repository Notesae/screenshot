# Liquid Symbiosis 2 · 动效规范

数值来自本包 `tokens.json` 与 `demo/engine.js`。CSS 像素，不是 Windows 物理像素。以下时长是设计参数，不是生产机测得的端到端延迟。

## 1. 驱动与中断

`engine.js` 统一调度感知场和命名时间线。弹簧质量为 1，半隐式欧拉积分，单步上限 1/120 秒，单帧累计上限 50ms；异常长间隔不累计成巨大的弹跳。

同名时间线启动时取消旧时间线，并返回取消结果。面板另有版本号，完成退出另有文档/代次保护。位移弹簧从当前 x/v 连续重定向；面板快速切换从当前显示矩形重新建立来源。

位置差小于 0.003、速度小于 0.018 时归到目标；连续 5 个静止帧后停止 requestAnimationFrame。重新输入、滚动或布局变化才唤醒。系统 reduced-motion 优先。

## 2. 主轨感知场

直接感知强度：`a = max(0, 1 - distance/radius)^2`，半径默认 110px。指针位于按钮外也可产生轻微响应；不可用、不可见和被水平滚动裁掉的按钮不参与。

同组第一邻居获得 0.28、第二邻居获得 0.10 的目标响应下限，取直接场和传导值的较大值，不无限叠加。完成/更多/收起不接受跨组牵引。

| 层 | 参数 | 表现 |
|---|---|---|
| 当前表面 | k520 / c29 | 迎向迅速，有小幅柔性回落 |
| 邻近表面 | k340 / c27 | 弱传导，不与主按钮抢响应 |
| 底座 | k240 / c26 | 吸收张力，边缘曲率轻微改变 |
| 表面位移 | X 3.8 / Y 5.2；向量长度封顶 6.5 | 命中槽位不动 |
| 形变 | 基础拉伸系数 0.065 | 只影响材质层 |
| 图标 | 跟随表面位移的 0.38 | 不按材质比例拉伸 |

设计台可调强度与半径，并导出当前候选 Token。最大位移仍受约束，不把调参变成脱离点击区域的漂浮。

## 3. 液态共生 B

触发：指针跨越同组相邻按钮，且与上次触发间隔至少 90ms。最多同时一条桥；最长存活 210ms。稳定停留后自然收细并消失。

连接使用按钮相向边缘的平滑曲线，最大间隙 18px，颈部 5px，透明度峰值 0.85。两端跟随表面实际受限位移，不能连接到已经离开屏幕的按钮。几何与光泽采用同源材质，桥不接收点击。

卡片连接属于另一种关系：仅在来源按钮与新卡片近邻时使用，距离限制 58px 附近的连接条件。来源过远时只保留方向性成长；不为“液态”而画长触须穿过内容。

## 4. 按压与选择

按压：目标表面 X 到 1.065、Y 到 0.855，k680/c27；按下阶段冻结主动迎向。相邻表面获得 19 的小速度冲量，随后自然回落。这是真实参与求解的冲量，不是文档中的占位参数。

选择：逻辑点击立即改变工具；蓝色材质 k470/c30 从当前槽位迁往新槽位，并按速度产生有界拉伸。hover 不改变逻辑选择。文字与图标不被 goo/filter 模糊。

## 5. 入场、脉冲与光

工具轨底座从约 6% 横向展开；按钮表面和图标从完成端方向挤出。完成按钮最先归位，其余按 14ms 间隔错峰。弹簧 k620/c35。

入场后的轨面扫光 420ms，仅播放一次；松手光脉冲 430ms。光层不接收输入，不能盖白标签。背景与截图内容不做全屏视差或缩放。

尺寸胶囊的文本与尺寸值即时更新，外壳仅允许约 5/4px 的短惯性位移；不是让读数追赶真实尺寸。停止拖动后回流，不留下尾随窗口。

## 6. 浮卡

从来源矩形到目标矩形使用 k440/c32。卡片材质轮廓生长，内容在后段独立淡入；没有把长文本作为一张位图缩放。

关闭约 170ms，向来源方向轻微回收。快速开关会取消旧时间线；快速切换卡片时旧关闭不得把新卡片隐藏。

位置选择先避让工具轨，后减少与截图内容重叠。布局变化重新测量固定槽位，不能持续读取形变后的按钮位置作为新的布局目标造成正反馈漂移。

## 7. 完成与取消

完成按钮按下只进入可取消等待。模拟业务成功且任务戳有效后，才播放约 360ms 收束：图像展示副本朝完成点收缩为小体积，工具轨向完成端回收，遮罩离开。副本不改写原图。

收束结束后清空当前编辑，提示明确说明“演示完成，未写入系统剪贴板”。失败和过期都保持现场，不播放成功聚合。

收起/最终 Esc 不冒充完成：边框与工具轨轻微下沉，有限碎屑退出，然后隐藏但保留文档。只有用户选择“恢复编辑”才恢复本次保留内容。

## 8. 基础交互

提示以短位移和体积回流进入，错误不自动消失。位置避让工具轨；通知正文不抢点击，关闭按钮可点击。开启新任务时清理旧提示，避免把不同任务状态叠在一起。

滑杆数值即时，凸面滑块与凹面轨道表达触感；一个拖动只产生一次撤销记录。颜色用草稿确认，不把关闭当作提交。

折叠区约 190ms，从当前高度转向新目标。重复点击取消旧高度动画；结束后释放固定高度。正文不弹跳。

## 9. 减少动态与低开销

减少动态：临近位移、形变、液桥、光脉冲、粒屑关闭；业务状态不变。已运行时间线立即到正确终态，弹层不会残留半透明层或失效的命中区域。系统偏好不能被应用关闭。

低开销：关闭液桥和指针追光，保留直接反馈与主要状态转换。不是降低精确坐标更新速度。

本轮没有宣称 60/120/144Hz 真机预算达标；录制视频也不是帧率基准。实际桌面性能与视觉质量必须在生产集成后另行验收。
