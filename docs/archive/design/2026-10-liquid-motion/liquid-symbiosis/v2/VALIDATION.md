## 并非一开始就全绿

任务组早期正常点击因错误通知挡住“完成”超时。修正通知位置、指针命中和新任务清理后重新执行，通过。没有用 force-click 绕过遮挡。此发现同时写入 CHANGELOG。

本轮另外修正设置错误不可见、空文档取消返回、裁剪坐标缩放、离画布标注项目兼容、选择器展开态、尺寸胶囊无效位移以及导入图上下手柄不缩放；没有把这些本轮发现全部宣称为旧版缺陷。

## 真正运行过的输出检查

文件组实际生成 PNG，并读取导出像素，核对实色遮盖区域不透明。实际下载、重新打开包含图片像素的演示项目，并核对原图尺寸与标注。导入一张 640×360 合成 PNG，验证其像素没有被示例画面替换；上下手柄实际调整显示尺寸且不改原图尺寸，2× 导出尺寸为 1280×720。

主交互检查按钮外观矩阵发生变化但外层命中盒坐标不变；指针离开并停稳后帧计数不继续增长。这证明对应机制，不证明 Windows 帧率、功耗或所有硬件上的流畅性。

## 视觉及录像

实际查看暖泥主界面、美化、深暖灰及窄窗口截图，检查工具轨与浮卡遮挡。previews/ 的图片来自浏览器渲染，不是概念合成图。

Liquid-v2-walkthrough.mp4 是实际浏览器指针与点击驱动的约 14 秒录制，展示沿轨道移动、手绘矩形、美化、原位翻译模拟、对照阅读和确认退出。只叠加了可见指针，未改写动画状态或加速播放。它不是正式 Windows 应用录像，也不覆盖全部状态。

此环境拒绝 file:// 导航，实际通过 page.set_content 加载同一个自包含 HTML。离线资源均已内嵌，但不将本环境下双击文件声称为已实测。推荐用户在桌面浏览器打开后评审实际观感。

## 未验证和原型限制

真实桌面捕获、系统剪贴板、热键、托盘、AI 服务、OCR 质量、WPF/WebView2 合成、DPI/高刷新率、中文 IME、系统更新与安装均未执行。服务/更新/复制等仅本地模拟，页面不收集 API 密钥。

部分失败重试是合成演示，不是生产按块续传算法。阅读正文和原位译文是固定样例。临近感知、卡片与退出采用有界弹簧和几何插值，不是完整流体求解。截图源是浏览器合成桌面，项目格式不兼容正式应用。预设与服务仅保存于本次原型会话。

没有测得或承诺生产时延预算；没有宣称“无 Bug”或完整无障碍认证。主观动效丰富度及是否达到原 G 的观感，需要用户实际对照。
