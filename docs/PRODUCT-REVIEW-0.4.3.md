# 产品改进记录（0.4.3 开发中）

本轮保留“截图后原位编辑、主动进入高级工作台”的产品方向和共享文档/渲染内核。审查使用新建无头 Edge、内存合成素材、模拟宿主，真实桌面测试仍暂停。截图与详细 JSON 保存在忽略目录，不提交用户内容。

## 第一轮：入口、编辑连续性与异常反馈

1. 核对 SCOPE、BRIDGE、TASKS 和原位设计，参考既有离屏预览，再采集 `artifacts/qa/product-round-1/before-stable/`。最初未等画布自适应完成的一张截图被拒绝，未把瞬态当作缺陷。
2. 空状态：原界面无图片时暴露整套不可用表单。现在说明导入/标注/导出流程，内容就绪后再显示编辑器。
3. 导出入口（高影响）：1280×800 中导出区原位置 y=1933，需要滚过整套工具。改为独立滚动检查器与固定导出区，现 y=661；1000×620 中 y=481，顶栏 y=0，外壳不滚出窗口。
4. 选择连续性（高影响）：复制会丢掉对象选择，紧接删除无效。独立模型导出保留选择，复制后可立即删、撤销、重做；新增受保护 Delete/Backspace，输入框、IME、Fabric 文字编辑及修饰键不触发对象删除。
5. 原位工具：增加直接实色遮盖入口；滚动选项时标题/关闭按钮可达；关闭返回触发按钮。完整工作台仍是主动操作。
6. 文字流程：离线 OCR 先显示本地状态和识别动作，翻译服务及收费能力探测后置；没有服务时禁用相应云操作。本地模型不自动下载。
7. 异常保护（高影响）：空 OCR 结果明确提示并保留既有校对正文/译文；失败不清空内容，自动保存失败可显式重试。画布更新时导出显示禁用状态，仍保留内核版本核对。
8. 视觉与动效：沿用暖色纸面与赭色强调，工具文字提高到主要 12–14px、辅助 11–12px，降低浅色字比例；面板仅 140ms opacity/transform 入场，通知 120ms opacity，减弱动效偏好禁用可见动画。
9. 复验：`product-audit.cjs --verify` 保存 13 张当前状态 PNG、14 条几何/操作记录，覆盖空/长文本/短窗口/加载/失败/模型缺失/恢复重试。既有 24 组离屏检查继续覆盖选区、裁剪、原样像素、OCR 遮盖、双语导出、块重试、过期响应及持久化。完整后台验证：53 前端、190 原生纯模型/假捕获、18 模拟 HTTP AI、56 SQLite、16 源码 OCR 算法及17含合成CPU模型检查通过。
10. 下一轮：性能驱动测量“原样画布中修改不可见校对文本”是否仍解码整张 4K 图，以及是否丢掉标注选择；优先修复这个可复现的编辑摩擦。另有英文单词断行、标注属性与选择同步、复杂原位面板遮挡待审查。不能把第一轮通过等同产品全部完成。

## 证据和验收边界

- 前后截图：`artifacts/qa/product-round-1/before-stable/`、`verified/`；同编号便于比较。`verified/audit.json` 记录动作/几何，`verify.log` 与 `legacy-headless.log` 保留回归结果。
- 可复现：先构建 editor，再运行 `node editor/scripts/product-audit.cjs <输出目录> --verify`；Playwright 路径由 `PLAYWRIGHT_MODULE` 提供。`product-performance.cjs` 支持 `SCREENSHOT_BENCH_DIST` 指向保留旧包进行相同驱动对照。
- 界面健康：主要编辑和错误路径已有可重复证据，仍需后续轮次处理剩余项；没有宣称完整无障碍、真实桌面帧率或现实 OCR 准确率验收。
- 仍待用户授权实机验证：真实捕获像素、负坐标/混合 DPI/多屏/插拔、窗口吸附/客户区、透明覆盖层、全局快捷键、系统剪贴板、实际拖放/焦点/对话框和中文 IME。真实服务端/密钥、干净机器与公开分发条款继续待单独验收或决定。
- 暂不扩展滚动截图/钉图/云同步、安装器/签名/更新/卸载、额外字体或 ARM64。Vite 500kB 主包警告保留，性能结论以实际数据为准。
