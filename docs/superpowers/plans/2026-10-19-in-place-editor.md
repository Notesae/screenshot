# 截图原位编辑调整

用户要求截图完成后保留冻结桌面与原选区，紧凑工具围绕选区出现；工作台是显式高级选项。此调整沿用已批准架构和现有文档状态，不另外创建编辑器。

## 模块与实施顺序

1. native_host：捕获返回裁剪图、冻结背景和物理像素几何；同一窗口切换无边框置顶原位层；以 captureId/ready 确认防止旧工作台闪现和过期唤醒；退出时释放背景；取消捕获恢复之前状态。
2. editor：复用 App 文档、Fabric Canvas 与导出路径；按虚拟桌面与实际 viewport 的独立 X/Y 比例定位选区；美化留白向外展开；工具条/属性面板限制在主要交叠屏幕；处理 Esc、中文组合输入和 Ctrl+C 焦点上下文。
3. integrator：审查两端契约和生命周期，补充测试记录，隔离构建/发布，核实提交和远端 CI。

冻结整桌面只保留在原生内存中，前端、项目文件、导出和 AI 只接收裁剪文档。显示元数据不写入项目，打开项目与普通图片走工作台。隐藏原位层仍保留未保存的内存文档，当前没有自动恢复。

## 后台验证

- 合成负坐标、多屏和不等 X/Y 缩放，验证选区映射、留白锚点、工具条和面板边界。
- 纯状态机验证准备、确认、取消、切换工作台、隐藏、过期 captureId 与重复热键门控。
- 纯键盘规则验证 IME、文本输入/Fabric 编辑、面板关闭、对象退出、最终 Esc 隐藏及图像复制意图。
- npm 测试/构建、隔离 .NET Release 构建、原生与 AI 断言运行器；不启动应用或实际遮罩。

## 实机验证限制

用户因影响正常工作明确停止桌面交互测试。禁止操作鼠标、键盘、焦点、窗口、文件对话框、剪贴板、热键和屏幕捕获；不得为清理而关闭现有窗口。真实透明合成、物理定位、混合 DPI、Esc/focus、中文 IME、热键重入及原生对话框置顶关系保持未测试，不能由单元测试推断通过。
