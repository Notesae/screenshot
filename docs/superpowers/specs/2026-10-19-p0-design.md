# 下一阶段 P0 设计

用户于上一阶段提交 296c1be 后明确授权继续 TASKS.md 中的 WGC、基础标注/历史、本地 ONNX OCR，随后衔接校对/双语与 SQLite 自动保存。沿用现有原位流程和安全边界，按可验证切片提交，不等完整产品再保存。

## 约束

- 所有实际桌面交互测试继续禁止，包括捕获、窗口枚举/弹出、键鼠、焦点、剪贴板、热键。仅合成 PNG、纯状态、模拟协议和独立 headless 浏览器。
- 两个实现模块优先并行；编译最多使用两个 MSBuild 节点，OCR intra-op 2/inter-op 1，避免占满机器资源。各模块使用独立 artifacts 目录。
- 冻结整桌面仅在原生层。前端、项目、OCR 与外部 AI 只接收文档内容；服务密钥仍只在原生进程。
- 不付费、不签新专属协议、不下载不明模型。公开许可证、模型来源、SHA256 与二次分发归属一并归档。运行时不静默下载。

## C1 捕获

保留 ICaptureBackend 边界，改为带 CancellationToken 的异步请求。WGC 为主后端，GDI 仅显式兼容选择，不静默降级。显示器/窗口目标采用显式标识，无测试脚本枚举真实窗口。逐屏 SDR 帧以物理像素拼成原生冻结背景，原有选区及 captureId/ready/dismiss 生命周期继续生效。

帧池、捕获会话、帧、D3D 设备与深拷贝生命周期独立封装。Resize 释放旧帧后重建池；超时、取消、目标关闭、权限/设备错误返回明确错误。首批 SDR 不承诺 HDR/受保护内容或跨屏同时帧。采用已安装 Windows 工具链或许可明确的互操作实现；若出现必须新接受的 SDK 条款先单独报告。

## E1 编辑与历史

项目升级 schemaVersion 2，读取兼容 v1。原始 image 为不可变共享资产引用；新增原图坐标 crop 与等比 resize，不为每次历史复制 Base64。受限历史快照覆盖样式、文本、模式、标注、裁剪/缩放、OCR/AI 合并；输入和拖动按事务合并，新编辑清 redo，新文档重置历史。

基础白名单包括 text/rect/arrow/highlight/cover；cover 导出为不透明实色。裁剪、缩放均从原始图计算，预览与导出共用路径。原样/美化留白变化保持内容与标注锚点。文字卡片进出维持单独画布坐标语义，不能宣称通用图内重建。

## O1 本地 OCR

选用 PP-OCRv5 mobile 检测与识别 ONNX 制品。上游 PaddlePaddle 官方模型卡明确 Apache-2.0 且非 gated；转换制品由 RapidAI 官方固定 v3.10.0 registry 提供下载 URL 与 SHA256。完整溯源见 models/pp-ocrv5-mobile/manifest.json 和 OCR-MODELS.md。

采用 Microsoft.ML.OnnxRuntime CPU 与 OpenCvSharp（分别 MIT/Apache-2.0），避免引入依赖 Emgu 双重许可的包装层。不依赖 Python 或 GPU；模型作为显式准备的本地包，缺少/错误哈希时返回不可用，不联网补齐、不伪造识别结果。

输出含模型版本、原始内容尺寸、稳定块 ID、四边形、阅读顺序、原始文本与可空置信度。字典与前处理按固定模型匹配；DB 检测后处理、透视校正、CTC blank/重复折叠与取消都单独测试。测试只生成自己的中英文字样，记录实际错误与耗时，不用上游许可不明示例图。

## E2 与 S1 衔接

校对保留 originalText 与用户修订，译文按块 ID 和发起修订号合并；旧结果不覆盖新校对。原图、原文、译文与双语导出共享版本化状态。

SQLite 保存索引/版本化文档和独立哈希图像资产；事务写入与原子资产落盘保证可恢复。自动保存、重启恢复、最近项目与容量清理在后台可用临时目录/中断注入验证。恢复不自动弹出窗口、也不自动打开私人截图；用户通过产品入口选择恢复。

每个切片完成代码审查、单元/模拟/合成测试与隔离 Release 构建后提交推送，并跟进 CI。GUI 与硬件未测项持续标明，不通过构建推断实际 WGC、透明合成、混合 DPI、IME 或新机器兼容。
