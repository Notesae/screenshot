# 属性、断行与原位停靠审查（0.4.4）

本轮针对0.4.3剩余的三个具体问题，先用合成素材在新建无头Edge中复现，再修改。保持原位选区等效遮罩为主流程，工作台由用户主动进入。没有真实桌面/剪贴板/热键/IME/窗口或显示器枚举、用户恢复库或真实服务请求。

## 操作与观察

1. 新增红色矩形，展开标注属性。改前模型颜色`#b4432c`，字段却显示`#30332e`。现在字段读取同一个选中对象；非文字对象禁用字号，未选中时禁用应用并说明原因。
2. 改蓝色并撤销，再切换矩形/文字、修改字号、取消选择。改前撤销后的字段仍显示蓝色；现在稳定ID维持同一选择，模型变更同步字段。草稿只在显式应用后进入历史；无效字号显示8–240说明且不改模型。文档/项目不存选择状态。
3. 在360px文字卡片输入恰好填满一行的汉字，后接逗号。改前逗号落到下一行开头。现在常用闭合标点与前字、开括号与后字组合换行。范围参考[W3C CLREQ 6.1.1](https://www.w3.org/TR/clreq/)，不宣称完整标准或专业出版排版。英文词、组合字符和emoji仍按字素保护，预览/倍率导出共用布局。
4. 在顶部小选区打开更多。改前状态条与面板重叠约9691平方像素。现在工具与状态条作为一组停靠，面板选择图外侧边或上下空白，避免覆盖工具/状态条；合成用例交叠面积变为0，原始PNG字节不变。
5. 在右下角选区打开面板。工具/状态优先整体移到图外，画布锚点不动。若只能覆盖图片，则保留可操作工具及可滚动面板，不移动或缩放文档以腾位置。
6. 用负虚拟原点、跨屏及独立X/Y映射复验。工具/状态/面板保持在所选屏幕的映射边界内，选区原点与原样PNG不变。仅模型与合成浏览器证据，不代替真实混合DPI验收。
7. 在1120×360视口映射到270px高的副屏，再打开更多并进入工作台。初次新布局使面板过矮、完整工作台按钮被固定标题遮挡，原有离屏测试正常失败。修复为预留可用面板高度、工具条必要时滚动、面板滚动留白；最终普通点击通过，并额外断言整个按钮在标题下方。没有强制点击或放宽原有像素断言。

8. 追加500组固定种子几何扫查后，发现一个无交叠但面板只有约90px高的模型案例；对应真实离屏布局约108px，仅能露出标题和少量内容。修复为拒绝低于目标可用高度的候选，再回归500组零失败；几何锚点不变。新增08-mid-screen在不足292px的侧边空白中采用180–292px自适应宽度，保留可操作高度并避免覆盖图片；侧边确实不足时才使用可滚动覆盖候选，关闭恢复图片可见性，导出不受影响。扫查结果保留在本机geometry-sweep-before/after.json，CI制品editor-tests.json记录含500组扫查的通过结果，不能把500组合成验证当成真实多屏验收。

## 证据与限制

- `artifacts/qa/refinement/before/`为保留611ba59网页上的同素材改前截图，`final/`为最终版本；同编号可比较。最初属性截图未滚到字段，已拒绝并重新采集，未将不在画面中的字段当视觉证据。
- 可复现驱动：`editor/scripts/refinement-audit.cjs <目录> --verify`；同一个mock-host、禁止外部请求、8张合成截图与7组操作断言。`SCREENSHOT_BENCH_DIST`可指定保留旧包网页以重现改前。
- 行宽不足以容纳最小标点组合时按字素退化，保留所有原文，不自动缩字号或挤出可见墨迹。尾随空白可保留在逻辑行尾，源串完整；没有实现悬挂标点、两端对齐、所有Unicode断行类别或人工原文规范化。
- 选择恢复依赖文档已有稳定标注ID；新建标注都有ID。新文档/删除对象不自动选择另一个对象。原位与工作台重挂载不会把选择写入项目。
- UI/UX技能检索没有命中对象属性同步的直接规则，因此该修复根据仓库共享模型与实际操作证据设计；未套用无关的表单提交或移动端触觉建议。Product Design预检没有保存上下文，继续以仓库和合成截图为依据。
- 不新增IPC、权限、模型/字体下载、密钥或资产通道。后续资产方案需要先明确内存/落盘生命周期和项目兼容策略；涉及新权限或产品选择时另行报告。
- 真实桌面/透明合成、多屏旋转/插拔/IME与服务商、干净机器和分发决定仍未验收。Vite 500kB主包警告保留。

最终后台测试、制品哈希与CI结论在本轮证据目录和交付报告分别记录，只将实际通过项记为完成。
