# 0.4.7 更新功能审查

本次为提交前代码/模拟审查，不是实机安装验收。基于 v0.4.6 创建独立功能分支，维持 WPF/WebView2/React/TypeScript 架构，未新增依赖。

已发现并修复：

1. 设置请求本身持续等待，若笼统禁止 busy 会永远无法安装。改为命名设置操作特例，其他本地/AI 任务仍阻止退出，增加真实 React + 内存宿主无头联调。
2. 同修订重复保存会被恢复库拒绝。更新前使用独立恢复身份，保存失败阻止退出；初始空文档不消耗恢复容量。
3. 故障回滚若先写日志，磁盘满会妨碍恢复。改为日志尽力写入，目录恢复优先，文件锁模拟日志不可写时旧版仍可恢复。
4. CreateNew 下载失败时不得删除已有目标；只清理本次确实创建的部分文件，并覆盖传输中取消、重试和既有文件保护。
5. 辅助进程超时后不能在用户稍后普通退出时意外安装。增加明确的交接确认/取消文件，只有确认交接且原 PID/启动时间吻合并退出后才执行。
6. 不能只比较 API 版本。执行阶段再次核对包清单摘要、当前安装摘要和 SBOM 版本，拒绝损坏、陈旧候选和降级。
7. 并排解压也不得形成可误用的半包。使用独立 partial 目录，全部验证成功后才改名为最终目录。

审查结论：本分支可提交 PR 供评审，不能据此发布或宣称真实自动更新已验收。私有远程获取仍阻塞在用户登录方案后续批准，源码默认匿名请求会明确报不可访问。当前 ZIP 没有独立发布者签名；信任边界和恢复限制见 [UPDATES.md](UPDATES.md)。真实安装/回滚/多实例交接、断电、权限、杀毒软件、首次条款确认与重启必须另行获准后验收。

无自动合并、tag、Release、仓库权限或产物公开操作。
