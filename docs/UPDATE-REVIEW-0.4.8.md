# 0.4.8 公开更新候选审阅

当前目标是固定 Notesae/screenshot 官方公开 Release 的免登录更新。PR #2 沿用原分支，但最终实现已删除 App Client ID、设备码、内存令牌及刷新路径；设置页不再以登录状态控制检查。版本递增0.4.8，尚未获准合并或发行。

## 核对结果

- 检查及下载前校验仓库不可变ID、full_name和公开状态；仓库迁移或变私有时失败关闭，不引入认证或备用来源。
- 匿名GET不带Authorization/Cookie；精确资产名、版本路径、唯一资产ID/API URL、长度、API SHA-256以及包内全清单/SBOM验证均保留。CDN仅既有官方白名单。
- 默认只稳定版，API预发布标记及SemVer预发布后缀都排除；主动选择才纳入预发布。只有预发布时显示可操作提示，不误报最新版，不降级或重复安装。
- 同一source串行请求，限流截止前不再请求；会话在清理暂存之前拒绝重复下载，取消后重试。UI延迟进度有操作代数保护，不覆盖后续操作。
- 保存未保存文档、退出交接、双阶段目录切换、备份、恢复与回滚机制沿用原实现；新增门控不触碰用户数据路径。失败保护继续由GUID隔离夹具验证，.exe为文本。

本机原生367（公开源55、更新隔离96），前端71、模拟AI18、SQLite56、OCR算法16/固定CPU合成17、发布模拟8、无头更新联调2及完整构建通过。真实匿名访问/下载证据、候选静态验证和失败记录见VALIDATION.md；最终精确提交CI以PR检查为准，不用旧head CI替代。

## 保留限制

API摘要与同源清单是完整性检查，不是独立签名。匿名API限额按共享出口计算，限流期间需等待或由用户手动从官方Release获取文件，不读取凭据绕过。已发布0.4.7登录门控无法由公开仓库动态解除，未来0.4.8获准发行后需手动迁移一次。

真实WPF交互、Windows辅助进程退出/重启/回滚、UAC、只读介质、杀毒软件及断电仍未实测；没有覆盖用户安装、启动真实安装或进行设备授权。当前审阅仅支持保留草稿和评审发布候选，不能宣称完整实机验收。
