# Screenshot 体验改版计划：以截图后原位编辑为中心

> **状态：待用户审阅，尚未授权实施。** 本次只提交计划，不变更功能、测试、Actions 或发布版本。后续先确认方案与关键画面，再决定实施范围；桌面操作暂停仍有效。
>
> 依据：2026-10-20 的用户讨论与 main `ca9d562d2a79dc6e9aad96e979c9d48b171474f2`（v0.4.8）。没有取得当前实际 UI 截图，也没有进行视觉或实机交互验收。历史合成画面不能代替当前使用现场。

## 1. 目标与边界

- 取消主工作台作为产品中心，移除启动空白页、常驻三栏和“完整工作台”产品入口。日常从托盘或快捷键开始截图，确认选区后原位编辑。
- 保留并强化现有原位编辑，让普通截图、预设美化、OCR/翻译各有短路径。复杂参数按需展开，不让普通截图经过配置页。
- 设置、历史/恢复、打开图片或项目作为低频独立入口；取消工作台不能丢失既有能力。
- 改进信息层级、组件质感、操作反馈与空间安排，不以单纯换色作为完成标准。

本轮不建设大而全工作台、图库管理系统、云同步或新 AI 功能，不继续 OCR 性能研究，不新增付费依赖或静默下载模型。文字卡片不升级成 AI 图文重建。保留 Windows 优先的 .NET/WPF/WebView2/React 架构、共享文档与渲染内核；取消产品入口不等于删除承载编辑器的原生窗口。

## 3. 入口与能力去向

| 现有入口/能力 | 改版后的建议去向与保留要求 |
| --- | --- |
| 启动工作台、托盘恢复工作台 | 条款门禁仍先于任何截图/热键能力；完成后以托盘为入口，默认主动作是截图。托盘不可用或热键冲突时提供明确、可恢复的入口，不能只在后台失败。 |
| 区域、屏幕/窗口目标、捕获设置 | 托盘“截图”保留常用目标；后端兼容选项、目标细节和热键配置进入设置。保留选区确认前调整、吸附、取消及已有捕获能力。 |
| 导入、粘贴、拖入图片、打开项目 | 托盘“打开…”和原位“更多”可达；进入同一轻量编辑器。文件输入没有冻结桌面时用中性背景承载，不伪造选区坐标，也不恢复大工作台。大图仍可查看、缩放和导出。 |
| 标注、裁剪缩放、撤销重做 | 原位主工具条保留常用标注；选中后展示适用属性。裁剪/尺寸等低频设置按需展开，仍使用同一文档和历史。 |
| 美化和样式预设 | “美化”先给少量预设与实时预览；留白、背景、圆角、边框、阴影等细调折叠展开，可明确返回原样。保留现有预设能力。 |
| OCR、校对、翻译、文字复制 | 进入独立的文字面板，按识别、校对、翻译、复制顺序展开。服务商配置移入设置，常用引擎/语言仍可就近选择。 |
| 文字重排 | 保留为低频“生成文字卡片”输出，支持现有原文/译文/双语布局和返回原图；不占据默认主导航。 |
| 自动恢复、项目保存 | 托盘低频“历史/恢复”入口承接现有快照列表、恢复与清理；“更多”保留打开/保存可编辑项目。现有恢复快照不等于永久截图历史，不扩大保存或清理策略。 |
| PNG 复制/保存、导出倍率 | 保持主工具条直接可达；1×/2×等选项进入导出选项，不改变原始像素、裁剪或脱敏语义。 |
| 设置、更新、条款、服务诊断 | 托盘独立入口，原位“更多”也可进入。保留版本/更新通道、下载取消重试、备份回滚、服务配置与条款查看，不在画布周围常驻展示。 |

**文字卡片的边界：** 当前 `reflow` 是把校对文字排成阅读卡片，不是理解原截图后重新安排图文，也不是重建原应用界面。本轮建议保留该能力但降低入口层级；是否后续移除另行确认，不先删除项目兼容或既有输出。

## 4. 默认主路径与结束行为

三条路径都从“托盘/快捷键 → 框选并确认 → 原位编辑”进入：

1. **普通截图：** 默认原样，必要时标注或遮盖，直接复制/保存 PNG；不要求选择模式或打开高级参数。
2. **预设美化：** 点击美化，选择预设后预览，直接输出；需要时才展开细调。切换样式不丢标注和撤销历史。
3. **OCR/翻译：** 打开文字面板，用户明确发起识别，校对后复制文字；需要翻译时再明确选择语言并提交。文字卡片是可选输出，不成为必经步骤。

建议默认：复制/保存 PNG **成功后**收起原位层、释放冻结背景、返回托盘；提供明确的继续编辑选择。该默认需在方案审阅时确认。取消文件对话框、导出失败、恢复快照失败时保留文档与可操作提示，不把“已复制图片”当作“可编辑项目已保存”。

Esc 依次处理中文输入/文字编辑、对象选择、展开面板，最后才收起编辑层；收起不等于清空文档。新截图取消应恢复之前的编辑状态。新截图覆盖旧内容、退出应用或更新重启前，继续保护未保存项目；无法可靠保存恢复快照时保留编辑状态，允许手动保存或明确放弃，不能悄悄丢失。截图失败和编辑器未就绪的出口也要改成重试/恢复/设置，不能再依赖完整工作台兜底。

## 5. 拖动组件与编辑对象是两件事

**工具条/面板位置：**

- 保留现有自动避让，优先放在截图外；工具条使用明确拖动把手，属性面板使用标题区拖动，不能让按钮、文本选择与拖动抢操作。状态反馈默认随工具组移动，是否独立浮动待审阅。
- 手动拖动只改界面位置，不移动截图、不改变选区或导出坐标。用户调整后不因普通重绘跳回自动位置；首次建议仅在本次编辑会话保留，跨会话记忆另行确认。
- 按所在屏幕的可用区域约束边界；换屏、DPI/分辨率变化后校正。大选区没有外部空白时允许紧凑收起和手动挪位，不承诺所有情况下完全不遮挡，也不把工具画进导出图片。
- 提供“重置工具位置”恢复自动安排，并提供键盘/点选移动或恢复方式；拖动不能成为唯一操作途径。

**画布内对象：**

- 选中标注后可移动、缩放，文字可直接进入编辑；选中状态与控制柄清楚，属性只针对当前对象，非文字不展示可用字号操作。
- 对象编辑沿用共享模型、稳定 ID、撤销重做与项目保存；改样式和布局不能重建后丢选择或打断中文输入。
- 工具位置与对象内容状态分开。拖面板不能变成拖标注，画布显示缩放不能改变导出像素。先核对既有能力实际表现，再修具体问题，不重写已有效的编辑内核。

## 6. 视觉方向与交付顺序

视觉以截图内容为主体，统一工具条/面板的尺寸关系、间距、圆角、图标线条、按钮层级与焦点样式。常用动作稳定可见，低频项逐层展开；选中、禁用、加载、成功和错误使用一致语言，不只靠颜色或悬停解释。弹层打开/关闭后焦点回到合理位置，异步结果不抢走当前编辑。使用可读的系统中文字体，不为外观静默下载字体。

不在本文预定最终配色、材质或效果；先审阅普通截图、美化展开、文字展开三个关键画面，再确认视觉方向。界面改版必须同时改善布局、交互和反馈。

| 阶段 | 小范围交付 | 完成条件 |
| --- | --- | --- |
| 0：方案与画面审阅 | 入口/能力去向、结束行为、三种关键状态示意；明确“定死”的具体目标 | 用户确认取消工作台后的能力去向、可拖动范围和关键画面，才开始实现；尚未确认的选择逐项保留。 |
| 1：入口与能力迁移 | 托盘/快捷键作为日常入口；设置/恢复/打开文件独立可达 | 不再强制出现大工作台；表中既有能力都有入口；启动条款、错误恢复、未保存内容保护不退化。 |
| 2：原位交互整理 | 自动/手动位置、边界与重置；选中对象属性和文字编辑 | 工具拖动与内容编辑互不干扰；大选区、屏幕边缘及DPI变化有恢复方式；撤销、输入焦点、项目和导出语义保持。 |
| 3：统一视觉并收尾 | 用统一组件完成三条短路径，清理重复入口与文案 | 常用流程不经过高级设置；反馈明确、输出与恢复完整；用户审阅实际画面，未测项按事实列出。 |

阶段表示审阅顺序，不把每个小项拆成 PR，也不并行铺开额外工程。后续实施只复用现有检查做针对性回归，不新建测试工程、不扩展性能研究。真实 Windows、混合 DPI/多屏、中文输入和原生对话框验收须另获明确授权；CI、代码阅读、模拟宿主或合成画面均不能替代桌面验收。

## 7. 全程保留的约束

- 原生宿主持有 OS 能力与服务密钥；前端不接收 API Key、更新凭据或任意安装命令。保持受信任来源、捕获身份、迟到结果和共享文档保护。
- OCR/翻译仅在明确操作后执行；保留本地/云端区别、输入范围、费用与失败反馈，不自动上传截图或静默改用云端。
- 保留实色遮盖、PNG/文字复制与导出、项目兼容、恢复库和隐私提示。可编辑项目及已识别文字仍可能含敏感原始内容，不能把隐藏工具或美化当作脱敏。
- 安全更新继续限定官方已验证来源、完整性校验、稳定/预发布区分、未保存项目保护与隔离恢复；同源 SHA 不等于发布者签名。安装版与便携版的现有升级路径均保留。
- 不改变用户数据目录、恢复容量、清理方式、首次条款确认或既有发布；本计划本身不代表这些行为已完成改版。
