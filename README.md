# Screenshot

一款 Windows 截图与图片编辑工具。截取屏幕、标注重点、美化图片，也能提取和翻译图片中的文字，方便记录问题、整理资料和分享内容。

[下载预发布版](https://github.com/Notesae/screenshot/releases) · [反馈问题](https://github.com/Notesae/screenshot/issues)

## 可以用来做什么

- **截图与标注**：截取屏幕区域或打开已有图片，裁剪画面，用箭头、形状、画笔和文字标出重点，遮盖不想分享的内容。
- **美化与分享**：为截图调整背景、留白、圆角和阴影，让教程、文档和分享中的配图更整洁。
- **提取与整理文字**：识别图片中的文字，校对、复制，或重新排版成文字卡片。
- **翻译图片**：将外语内容翻译为中文，在原图位置查看译文，也可单独阅读翻译结果。
- **保留编辑结果**：复制图片、导出 PNG，或保存可编辑项目，方便之后继续修改。

## 内容由你掌控

本地文字识别无需联网。使用 AI 识别或翻译时，只有在你主动操作后，相关图片或文字才会发送给你配置的服务；服务密钥保存在本机。

目前处于预发布阶段，面向 Windows x64，提供安装版和便携版。
